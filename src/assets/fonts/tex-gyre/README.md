# TeX Gyre fonts

Locally hosted webfonts from the TeX Gyre project, distributed under the
GUST Font License in `GUST-FONT-LICENSE.txt` (LPPL 1.3c or later).

- TeX Gyre Schola 2.005: Copyright 2006, 2009 for TeX Gyre extensions by
  B. Jackowski and J.M. Nowacki, on behalf of TeX users groups.
- TeX Gyre Pagella 2.501: Copyright 2006–2018 for TeX Gyre extensions by
  B. Jackowski, J.M. Nowacki, et al., on behalf of TeX USERS GROUPS.
  Vietnamese characters were added by Han The Thanh.

Upstream: https://www.gust.org.pl/projects/e-foundry/tex-gyre

Sources: https://mirrors.ctan.org/fonts/tex-gyre/opentype/

The eight upstream OTFs (`texgyre{schola,pagella}-{regular,italic,bold,bolditalic}.otf`)
were losslessly repackaged as WOFF2 using FontTools. No glyphs were subsetted,
redrawn, renamed, or otherwise changed. Each family includes regular, italic,
bold, and bold italic. Embedded font naming and copyright records are retained.

Manifest: the corresponding eight `.woff2` files in this directory.
